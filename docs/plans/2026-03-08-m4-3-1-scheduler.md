# M4.3.1 Scheduler Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Complete `M4.3.1` by replacing the placeholder scheduler with a minimal async `TaskScheduler` that supports `cron`, `interval`, and `once` tasks via an injected executor callback.

**Architecture:** Keep the scheduler self-contained and process-local for now. Reuse `ScheduledTask` as the task contract, drive due work from `next_run`, and avoid wiring task CRUD or real runtime execution until later milestones. Inject time, sleep, and execution callbacks so the scheduler is deterministic under test.

**Tech Stack:** Python 3.11, asyncio, SQLAlchemy ORM models, croniter, pytest, pytest-asyncio
